## Manual checklist for you (5 minutes)

1. Power-cycle Drop-BMR1 → after reconnect, Sound Settings input should stay on
   your mic; output should be BMR1 at 44.1 kHz (menu bar → BMR1 Guard shows
   "output: 44100 Hz (A2DP)").
2. Start/stop a Codex dictation with Codex on "System Default" → speaker keeps
   playing, guard menu never shows BMR1 as default input.
3. Close/open the lid (sleep/wake) → same checks.

## Addendum (same day)

- **Menu bar icon bug fixed**: the original build used a nonexistent SF Symbol
  name, leaving the status item invisible. Now uses `hifispeaker.fill` /
  `hifispeaker` with a text fallback so the item can never disappear.
- **App icon added**: `Support/AppIcon.icns` (generated by
  `tools/makeicon.swift`), wired via `CFBundleIconFile`.
- **Multi-instance test**: two copies at different paths *did* run
  concurrently (no destructive conflict — both enforce identically — but
  duplicate icons/listeners). Added a single-instance guard: launching a
  second copy while one runs → the newer instance alerts briefly and quits;
  verified live (t+2s: two pids; t+8s: only the original). Survivor selection
  is oldest-launch-first with pid tiebreak, so simultaneous launches cannot
  both exit. Unit tests re-run: 23/23 pass.
